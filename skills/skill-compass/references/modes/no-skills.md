# No skills yet

Say you found no skills besides this one. Do not produce your own list of named skills to install - popularity and quality change quickly and `find-skills` tracks that; a list from memory will be stale or invented.

1. Ask what they mostly work on, if they have not said.
2. Hand off: if `find-skills` is available, suggest using it with search terms that fit their work; otherwise show `npx skills add vercel-labs/skills --skill find-skills` and two or three `npx skills find <term>` examples for their area.
3. Suggest starting with 3-5 skills they will actually use, and coming back to you to check for overlap before adding more.
4. One line: check a skill's source and audits before installing (`references/security-checklist.md`).
